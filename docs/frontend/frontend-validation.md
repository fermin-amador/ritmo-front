# Validación
Ejecutar pnpm install, pnpm typecheck, pnpm lint y pnpm build.
La configuración de Vitest queda disponible para nuevas pruebas, pero actualmente no hay archivos de pruebas en el proyecto. pnpm test requiere añadir una suite.
La integración en vivo y los permisos de administración requieren validación con el backend.
