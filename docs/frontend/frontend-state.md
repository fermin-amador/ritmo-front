# Estado
Sesión en sessionStorage (por pestaña); contraseña no persistida. Listado remoto con estados carga, error, vacío y éxito. Búsqueda y filtro locales. Formularios separados de datos remotos; recarga tras mutación. Confirmación antes de eliminar; operaciones bloqueadas mientras están pendientes. Respuestas de listados obsoletos se ignoran al cambiar de vista o cerrar sesión.
